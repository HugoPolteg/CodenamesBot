# CodenamesBot

### Fun project to use ML to play Codenames online

 **Idea:**
 1. Find all codenames cards (screenshot -> extract countors -> find pixel values)
 2. Categorize the cards by type (Normal, Green or Black)
 3. Find the word on the cards
 4. Find a word with semantic similarity to as many green cards as possible, but with low semantic similarity to black or normal cards.
